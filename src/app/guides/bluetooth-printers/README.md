# bluetooth-printers

## Purpose

The public guide for Bluetooth printers. It opens by saying this is the
least recommended way to print, then gives complete steps.

## Contents

- `page.tsx` — why a helper device is needed and which devices can be one
  (Chrome on Android, Windows or macOS, never an iPad), phone and laptop
  steps, Raspberry Pi
  steps (install Node 24 and git, clone the public repo from the `merqo-io` organization, run
  `bridge-agent/install.sh`, pair, choose the printer, start the service),
  and a troubleshooting FAQ.
  Headings use the display face; "Read this first" is a warning `Notice`; step numbers match the setup flows' `Step` marker.
  Ends with `SiteFooter` (sign-in shown), like every public page.
